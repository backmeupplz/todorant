          Como usar a matriz

          Escreve tudo o que tens em mente, uma tarefa de cada vez. Para cada uma, faz duas perguntas. É urgente: há um prazo próximo, ou alguém está à tua espera? É importante: faz avançar algo que te interessa? As respostas escolhem a caixa.

          • Fazer primeiro é para as tarefas urgentes e importantes. Faz-as hoje.
          • Agendar é para as tarefas importantes sem um prazo a pressionar-te. São as que se perdem, por isso dá a cada uma uma data.
          • Delegar é para as tarefas urgentes que não precisam de ti. Passa-as a outra pessoa, ou despacha as mais rápidas e segue em frente.
          • Descartar é para as tarefas que não são nem uma coisa nem outra. Podes apagá-las.

          A ferramenta sugere uma tarefa para fazer primeiro: a mais difícil da primeira caixa e, em caso de empate, a que foi adicionada mais cedo. Marca cada tarefa como Fácil, Média ou Difícil com honestidade e a sugestão será útil. É uma regra prática, não um oráculo; conheces o teu dia melhor do que uma página com quatro caixas.

          Perguntas frequentes

          O que é a matriz de Eisenhower?

          É uma forma de ordenar tarefas com duas perguntas: é urgente e é importante? As tarefas urgentes e importantes fazem-se já. As importantes mas não urgentes agendam-se. As urgentes mas não importantes passam-se a outra pessoa, se possível. As que não são nem uma coisa nem outra descartam-se. O nome vem de Dwight D. Eisenhower, a quem se atribui a frase de que o que é importante raramente é urgente e o que é urgente raramente é importante; a matriz em si foi popularizada mais tarde pelo livro Os 7 Hábitos das Pessoas Altamente Eficazes, de Stephen Covey.

          Como decido se uma tarefa é urgente ou importante?

          Urgente quer dizer que há um prazo próximo ou que alguém está à tua espera agora. Importante quer dizer que faz avançar algo que te interessa, quer alguém to peça ou não. Um teste rápido: se a deixasses de lado, arrependias-te daqui a um mês? Se sim, provavelmente é importante.

          O que quer a ferramenta dizer com «a que fazer primeiro»?

          Dentro da caixa Fazer primeiro, escolhe a tarefa que marcaste como a mais difícil e, se várias forem igualmente difíceis, a que adicionaste primeiro. Fazer antes de tudo a tarefa que mais temes é a ideia por trás do conselho «engolir o sapo», que é também a forma como o Todorant ordena cada dia. A ferramenta é uma sugestão, não uma classificação da tua vida.

          As minhas tarefas ficam guardadas em algum lado?

          Só neste navegador, no seu armazenamento local, por isso continuam cá quando voltares ao mesmo dispositivo. Nada é enviado para um servidor, e limpar os dados do navegador apaga-as. Usa «Copiar como texto» se quiseres guardar a lista noutro sítio.

          É gratuita?

          Sim, sem registo e sem anúncios.

          O Todorant mantém o hábito para lá de hoje. O Todorant é um gestor de tarefas gratuito e de código aberto na web, no Android e no iPhone. Não usa quatro caixas. Pede uma data em cada tarefa, marca como sapos as que temes para que venham primeiro no seu dia e mostra apenas a tarefa a fazer agora.
