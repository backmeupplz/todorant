          Como usar a matriz

          Anote tudo o que está na sua cabeça, uma tarefa de cada vez. Para cada uma, faça duas perguntas. Ela é urgente: há um prazo próximo ou alguém está esperando por você? Ela é importante: faz avançar algo que importa para você? As respostas definem a caixa.

          • Fazer primeiro é para tarefas urgentes e importantes. Faça-as hoje.
          • Agendar é para tarefas importantes que não têm um prazo apertado. São as que se perdem, então dê uma data para cada uma.
          • Delegar é para tarefas urgentes que não precisam de você. Passe-as adiante ou faça as mais rápidas e siga em frente.
          • Descartar é para tarefas que não são nem uma coisa nem outra. Pode apagá-las.

          A ferramenta sugere uma tarefa para fazer primeiro: a mais difícil da primeira caixa e, se houver empate, a que foi adicionada antes. Marque cada tarefa como Fácil, Média ou Difícil com honestidade e a sugestão será útil. É uma regra prática, não um oráculo; você conhece o seu dia melhor do que uma página de quatro caixas.

          Perguntas frequentes

          O que é a matriz de Eisenhower?

          É uma forma de organizar tarefas com duas perguntas: ela é urgente e é importante? As urgentes e importantes você faz agora. As importantes, mas não urgentes, você agenda. As urgentes, mas não importantes, você passa para outra pessoa, se puder. As que não são nem uma coisa nem outra você descarta. O nome vem de Dwight D. Eisenhower, a quem se atribui a frase de que o que é importante raramente é urgente e o que é urgente raramente é importante; a matriz em si foi popularizada mais tarde pelo livro Os 7 Hábitos das Pessoas Altamente Eficazes, de Stephen Covey.

          Como decidir se uma tarefa é urgente ou importante?

          Urgente quer dizer que há um prazo próximo ou que alguém está esperando por você agora. Importante quer dizer que ela faz avançar algo que importa para você, mesmo que ninguém esteja pedindo. Um teste rápido: se você deixasse de fazê-la, se arrependeria daqui a um mês? Se sim, provavelmente ela é importante.

          O que a ferramenta quer dizer com a tarefa para fazer primeiro?

          Dentro da caixa Fazer primeiro, ela escolhe a tarefa que você marcou como a mais difícil e, se várias forem igualmente difíceis, a que você adicionou antes. Fazer antes das outras a tarefa que você mais teme é a ideia por trás do conselho “engolir o sapo”, que também é como o Todorant ordena cada dia. A ferramenta é uma sugestão, não um ranking da sua vida.

          Minhas tarefas ficam salvas em algum lugar?

          Só neste navegador, no armazenamento local dele, então elas continuam aqui quando você voltar no mesmo aparelho. Nada é enviado a um servidor, e limpar os dados do navegador as remove. Use “Copiar como texto” se quiser guardar uma lista em outro lugar.

          É gratuito?

          Sim, sem cadastro e sem anúncios.

          O Todorant mantém o hábito depois de hoje. O Todorant é uma lista de tarefas gratuita e de código aberto, na web, no Android e no iPhone. Ele não usa quatro caixas. Pede uma data para cada tarefa, marca como sapos as que você teme para que venham primeiro no dia delas e mostra só a tarefa que você deve fazer agora.
